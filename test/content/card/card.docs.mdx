The Card component is a flexible container for displaying various types of content. It supports a variety of features like headers, footers, images, and different visual styles.

## Basic Card

This example shows a simple card with a title and some content.

```jsx
<Card title="Simple Card">
  <p>This is the content of a basic card. It's simple and clean.</p>
</Card>
```
## Card with Header and Footer
Cards can include headers and footers for more structured content.
```jsx
<Card
  header={<h4>Featured Article</h4>}
  title="Article Title"
  footer={<button>Read More</button>}
>
  <p>This card demonstrates the header and footer sections, perfect for previews or summaries.</p>
</Card>
```
