A versatile and brand-conscious logo component tailored for Acme, with the ability to adapt to diverse presentation needs. Displays the Acme logo by default. Allows override with props for name, href, logo size (in pixels), slogan and optional SVG logo.
Uses the Link component to navigate to `href` upon click.

## Component Usage

### Default Acme Logo

Displays the default Acme logo with a slogan.

```jsx
<Logo slogan="Your Trusted Partner" />
```

### Custom Logo with Link

Shows how to use a custom name, slogan, and link for the logo.

```jsx
<Logo name="Nova Corp" slogan="Innovate. Integrate. Inspire." href="/nova-corp" />
```

### Minimal Logo

Demonstrates the minimal mode, which displays only the SVG logo.

```jsx
<Logo name="Acme Minimal" minimal href="/minimal" />
```
